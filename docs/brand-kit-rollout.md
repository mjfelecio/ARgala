# ARgala Seafoam Forest v2 integration — 2026-11-02

The approved v2.0 identity supersedes the v1 artwork colors. The familiar
Clean Explorer green/white/mint UI remains: primary actions #247A53, stronger
green #174D38, existing text/surfaces, route blue and native AR palette.
Navigation, permissions, admission, provider requests and session behavior are
unchanged. Plus Jakarta Sans remains the UI font; logo lettering is outlined.

## Audit and integration decisions

The existing SDK 57 app uses Android-only Expo configuration with generated
native projects, UniWind and HeroUI Native. `global.css` remains the single token
source. The supplied README, PDF, tokens, contrast report, reference components,
SVG masters, icons and supporting UI assets were reviewed alongside current
Welcome/auth/Explore code and the owner's HOP/HOP-Driver auth examples.

Three artwork-only tokens are retained: `logo-seafoam` #42D5A5, `logo-ink` aliases
the existing `brand-strong` #174D38, and `logo-ivory` #FCFBF7. The kit's suggested
semantic theme/spacing/radii and TS theme are not copied. Existing UI semantics,
selected/pressed/disabled/loading/field states and map geography remain intact.
Seafoam is decorative, never small action text on white or ivory. Compiled CSS
contrast checks cover white on app green, forest on seafoam and forest on ivory.

`BrandLogo` supplies proportional primary, horizontal and mark variants with
one accessible ARgala label, or hidden decorative ownership. The full primary
lockup replaces Welcome's old compass/title (144 dp); sign-in uses the horizontal
lockup (160 dp), and Explore uses a decorative mark (32 dp). The standalone mark
has one rounded foot of clear space on every side. Existing screen/hero geometry,
scrolling, keyboard handling, language previews and input interactions remain.

`JourneyMotif` replaces the former abstract Welcome/auth scenery at 10% opacity
inside the existing clipped hero. The v2 curved exploration path is a filled
shape; its exact geometry and destination dot are preserved. No decorative
patterns or new icon sets are added to maps, AR, destination photography or
utility screens. Other optional kit patterns, hero textures and empty states
were considered; the current placements provide sufficient branding without
adding clutter, raster downloads or new startup work.

## Production asset provenance

Source: owner-supplied `ARgala-Brand-Kit-v2`, v2.0 Seafoam Forest, generated by
its `Source/brand_kit_build.py`. Its guide describes a vector reconstruction of
the concept and URW Gothic Demi AR / Book gala converted to paths. Original v1/v2
kits and unrelated files remain untouched; only required production assets are
copied into the app. No SVG transformer, dependency or additional font is added.

The supplied adaptive foreground extended outside Android's central safe circle.
An outer `translate(51.2 51.2) scale(.9)` adds transparent padding around the
original `translate(233 272) scale(.93)` geometry. This preserves curves,
proportions and colors. Both color and monochrome layers use identical padding.
The PNG pixel regression checks all visible antialiased pixels against the
66/108 safe circle, transparency and the white-alpha themed mask. Native OEM
masks/motion still require device acceptance. [Android adaptive icon guidance](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive).

Regenerate the two derived PNGs after running the geometry script:

```sh
convert -background none assets/brand/adaptive-foreground-safe.svg -define png:color-type=6 assets/images/android-icon-foreground.png
convert -background none assets/brand/monochrome.svg -define png:color-type=6 assets/images/android-icon-monochrome.png
```

`app.json` owns launcher layers and the forest splash (#174D38), including the
same dark-OS treatment. `app.config.ts` retains the static splash plugin rather
than overriding it. The transparent splash icon uses a 160 dp canvas including
its supplied safety margin; the full-screen kit splash samples are not used as
Android launch icons. This adds no dark application theme or new splash timing.
The existing iOS config is inactive: the resolved app supports Android only.

32/64 dp marks and icon sizes, 144/160 dp lockups, inverse artwork, illustrative
launcher masks, splash source and Journey treatment. It is not an Android screen

`adb devices -l` found no connected devices on 2026-11-02. The earlier v1 phone
captures do not validate this v2 revision. No device data/settings were changed,
no paid request was started, and no APK was built. Native launch resources need
a separately approved rebuilt preview APK; Expo development-client launches do
not establish production splash appearance. [Expo SDK 57 splash documentation](https://docs.expo.dev/versions/v57.0.0/sdk/splash-screen/).

Remaining: actual launcher/themed masks and cold start in light/dark OS modes;
Welcome/auth/Explore in EN/JA/KO at normal and large text; keyboard and
loading/error states; collapsed/expanded docks and TalkBack. Native AR behavior
and appearance are untouched, and no new live AR/GPS/Maps claim is made.
Automated results are recorded in [validation evidence](validation.md).
