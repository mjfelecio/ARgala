## Interfaces and implementation rulings

- Keep the M1 square route intact; M2 is a second development-only route sharing preflight, foreground/stack/measurement gates. Release/dead links cannot evaluate Viro or start sensors.
- Geometry/controller are pure and do not grant geographic admission. Native per-frame callbacks update refs/native node transforms; React state changes only for initial capture, tracking changes or discrete user actions. Trial translation publication is capped at30Hz with a60ms smoothing time constant, 2mm deadband and25cm snap threshold; these are unverified engineering values, not quality claims.
- Ring yaw is captured once; translation follows the camera. Focus captures current heading once and stays world-fixed. Close targets the current ring; recenter cancels transitions and preserves selected ID/page. Native completion tokens fence stale callbacks. Same-frame tracking recovery never captures a new basis.
- Detailed mock content, paging, A−/A+ and Close remain Viro-native; Exit/Recenter/Help/status are ordinary utility chrome. Keep a single click owner per interactive surface and hold/release guidance.
- Native animation owns focus transforms (280ms trial). Tracking loss pauses it. No new animation library, frame history, logging, GPS or provider request.
- Pagination uses grapheme segmentation, conservative width/line budgets and source offsets for reflow. Width counts are provisional: they do not prove native font fit. Viro's world bounding box is a layout box, not a reliable glyph-overflow measurement. Actual fit/CJK/fallback at every size remain Gate B checks. No typography replacement to conceal integration issues.
- Grapheme segmentation uses the MIT-licensed pure-JS unicode-segmenter0.17.3, installed via Expo; Hermes cannot be assumed to provide Intl.Segmenter. No global polyfill/native module.
- Reading size is device-local, separate from general preferences; late loads cannot overwrite user actions. Writes are serialized; UI translates stable load/save failure keys and explicit recovery. No curated/provider content persisted.
