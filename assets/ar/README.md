# Native holographic artwork

Original ARgala interface geometry, generated from the committed SVG sources by
`scripts/generate-ar-holographic-art.py`. The script derives forest/seafoam from
`global.css`; PNGs are small native Viro textures, not destination photographs.
Run the script after changing the source geometry. FFmpeg with librsvg is a development
conversion tool, not an application dependency.

The surface is matte/translucent; it does not blur or replace the actual camera.
Chapter emblems identify Overview, History, Highlights, Visitor Notes and Facts;
unknown sections get a neutral document symbol. Brand logo geometry is untouched.
