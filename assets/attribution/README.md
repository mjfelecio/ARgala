# Google Maps attribution

Unmodified DarkGray PNG assets (1x, 2x, 4x) from Google's official
[attribution archive](https://developers.google.com/static/maps/documentation/images/Google_Maps_Attribution_Assets.zip), downloaded 2026-10-18.

Display at the original aspect ratio, 18 dp high, with at least 10 dp clear
space above/left/right and 5 dp below. These assets remain Google's marks;
see the [Places attribution requirements](https://developers.google.com/maps/documentation/places/web-service/policies).
